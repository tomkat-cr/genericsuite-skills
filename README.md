# Generic Suite Skills

Generic Suite skills, plug-in and other AI Agent resources

This is a **AI Skills Plugin Repository** for GenericSuite — a collection of AI agent skills that extend AI Agent's capabilities. Skills are self-contained directories under `skills/`, each containing a `SKILL.md` file and optional bundled resources (scripts, references, assets).
